---
description: Show how much tool output Sieve kept out of the context window
allowed-tools: Bash(sieve stats:*)
---

Run `sieve stats` with the Bash tool and show its output as it is. Do not round, re-estimate or extrapolate the numbers: they are measured by Sieve.

If `sieve` reports that it is not installed, tell the user to run `/sieve:install`.
